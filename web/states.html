Florida Live

The first state, live now — county-by-county tools built on Florida's own unusually strong public-records law:

  • Find your county's poll-worker application — paid work, and every county needs more people
  • Build a correctly-formed Chapter 119 public-records request in minutes, for free, with no account and no API key required
  • All 67 counties, sourced from the state's own official data — never a guessed contact or a constructed URL
